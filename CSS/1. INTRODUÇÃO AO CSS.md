O CSS, Cascading Style Sheets (Folhas de Estilo em Cascata), é uma linguagem de estilo usada para estilizar página Web.
Usamos ele para: 
- Definir o layout
- Definir o design
- Definir a tipografia
- Deixar o site responsivo
- E varias outras coisas que podemos definir com ele

#### Exemplo de um código em CSS

```css
/*Aqui estamos definindo que todos os parágrafos do site terão um tamanho de 16px;*/
p {
	font-size: 16px;
}
```

## Sintaxe básica do CSS

A sintaxe do CSS consiste basicamente de um seletor e um bloco de declaração.

![[css sintaxe|700]]

O seletor aponta para o elemento HTML que você deseja estilizar.
O bloco de declarações contém uma ou mais propriedades do CSS separados por ponto e vírgula `;`
Cada propriedade do CSS é declarada por meio de uma chave e um valor, sendo separados por dois pontos `:`

```css
/*P é um seletor do CSS (que aponta diretamente para o elemento p do HTML)
color é uma propriedade do CSS, aqui definimos que o texto de todos os parágrafos do site terá uma cor vermelha.
text-align está definindo que o texto deve estar centralizado.
Em outras palavras, color e text-align são propriedades, red e center são os valores atribuidos a elas.
*/
p {
	color: red;  
	text-align: center;
}
```

## Como adicionar CSS no arquivo HTML

Existem 3 formas de adicionar o CSS no arquivo HTML:
- Inline
- Interno
- Externo

#### Inline

Para adicionar o CSS da forma inline, devemos adicionar um novo atributo dentro de qualquer tag do HTML:

```html
<p style="color: red">Este é um parágrafo de cor vermelha</p>
```

>[!WARNING] Não devemos usar essa forma!!!
>Este foi apenas uma demonstração que existe essa forma, mas atualmente usamos CSS externo


#### Interno

Para adicionar o CSS da forma interna, declaramos a tag `<style></style>` dentro da tag `<head></head>` .

```html
<!DOCTYPE html>
<html>
	<head>
		<style>
			h1 {
				font-family: sans-serif;
			}
			h2 {
				font-family: "Inter";
			}
		</style>
	</head>
	<body>
		<h1>Este é o título principal</h1>
		<h2>Este é um subtitulo</h2>
	</body>
</html>
```

>[!WARNING] Atenção !
>Sempre devemos usar o CSS externo

#### Externo

Neste modelo, precisamos criar um novo arquivo dentro do nosso projeto, esse arquivo deve ter um nome e possuir a extensão `.css`. Para conectar o arquivo `HTML` ao arquivo `CSS`, devemos declarar uma nova tag chamada de `link` dentro da tag `head`. 

```html
<!DOCTYPE html>
<html>
	<head>
		<!-- Aqui linkamos o css externo ao arquivo HTML -->
		<!-- O atributo href deve conter exatamente o nome do arquivo css criado -->
		<link rel="stylesheet" href="nome-do-arquivo.css">
	</head>
	<body>
		<h1>Este é o título principal</h1>
		<h2>Este é um subtitulo</h2>
	</body>
</html>
```

```css
/*Arquivo css separado do html, onde definimos as regras e estilos*/
h1 {
	font-size: 24px;
}

h2 {
	font-size: 16px;
}
```

## Seletores

Para que o CSS consiga estilizar o nosso site ele utiliza alguns seletores para identificar qual a parte queremos alterar.

Existem diversos seletores CSS, os mais comuns são:

- Seletor de elemento (identificado pela tag HTML)
- Utilizando um identificador único, que é declarado no HTML por meio do atributo `id`
- Utilizando classes, que também é declarado no HTML por meio do atributo `class`

```html
<!--index.html-->

<html>
	<head>
		<link rel="stylesheet" href="index.css">
	</head>
	<body>
		<h1>Este é o título principal</h1>
		<h2 id="subtitulo">Este é um subtitulo, que possui o atributo id</h2>
		<p class="paragrafo">Este é um parágarfo, que possui o atributo class</p>
	</body>
</html>
```

```css
/*index.css*/

h1 {
	font-family: sans-serif;
}

/*Para chamar o elemento via ID, usamos # + nome do id*/
#subtitulo {
	font-size: 16px;
}

/*Para chamar o elemento via classe, usamos . + nome da classe*/
.paragrafo {
	font-weight: bold;
}
```

### Agrupando seletores 

O CSS nos permite declarar um bloco de propriedades com a mesma estilização para  vários elementos de uma só vez. Para isso, basta separar os seletores por vírgula.

```css

/*Dessa forma vai funcionar perfeitamente, mas podemos simplificar*/

h1 {
	text-align: center;
	color: red;
}
p {
	text-align: center;
	color: red;
}
h2 {
	text-align: center;
	color: red;
}
```

```css

/*Dessa forma nosso código css fica mais limpo*/

h1, p, h2 {
	text-align: center;
	color: red;
}
```

## Vamos praticar !!!

**Cartão de perfil**

*Passo 1*: Crie uma nova pasta e dentro dela crie 2 arquivos: 
*index.html* e *index.css*

*Passo 2:* Copie esse código para dentro do arquivo index.html

```html
<!DOCTYPE html>
<html>
    <head>
        <title>Perfil Dev</title>
        </head>
    <body>
        <h1 id="nome">Seu Nome Aqui</h1>
        <h2>Desenvolvedor Front-end</h2>
        
        <p class="descricao">Estudante de HTML e CSS apaixonado por código.</p>
        
        <ul>
            <li class="tech">HTML5</li>
            <li class="tech">CSS3</li>
            <li class="tech">Git</li>
        </ul>
    </body>
</html>
```

*Passo 3*: O desafio

1. Conectar o arquivo *index.css* no *index.html*. Use a tag `<link>`
2. **Nome (ID)**: O elemento com id *#nome* deve ter a cor azul e tamanho de 32px.
3. **Tecnologias (CLASSE)**: Os itens com a classe *.tech* devem ser negrito `(font-weight: bold)`.
4. Agrupar: O elemento *h1* e o elemento *h2* devem estar centralizados `(text-align: center)`. Agrupe os seletores para realizar essa tarefa.
