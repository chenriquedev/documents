
## Cores

Para especificarmos cores no CSS, podemos usar nomes de cores ou valores como RGB, HEX, HSL, RGBA, HSLA.

#### Alterando a cor do texto

Para alterar a cor do texto, usamos a propriedade CSS `color`, seguido de um valor correspondente à cor.
#### Exemplos

```css
/* Nome da cor (keyword) */
h1 {
    color: red;
}

/* Código RGB (Red, Green, Blue) */
h2 {
    color: rgb(255, 99, 71);
}

/* Código HEX (Hexadecimal - O mais comum!) */
p {
    color: #ff6347;
}

/* Código RGBA (O quarto valor representa a opacidade da COR: 0.5 = 50%) */
span {
    color: rgba(255, 99, 71, 0.5);
}
```

#### Alterando a cor de fundo 

Para alterar a cor de fundo do elemento, usamos a propriedade `background-color`

```css
/* Define um fundo cinza claro para todo o site */
body {
    background-color: #f0f0f0;
}

/* Define um fundo azul para o botão */
button {
    background-color: blue;
    color: white; /* Texto branco para dar contraste */
}
```

## Background

O CSS background é utilizado para adicionar efeitos de fundo nos elementos.

Nós temos a propriedade que já vimos anteriormente para adicionar cor de fundo no elemento, o `background-color` e podemos colocar uma imagem de fundo ao utilizar a propriedade `background-image`.

```css
/* Define um fundo azul para o botão */
button {
    background-color: rgba(0, 0, 255, 0.3); /* 30% de opacidade no FUNDO */
    color: white; /* Texto branco para dar contraste */
    opacity: 0.3; /*Adiciona transparência, deixa todo o elemento transparente.*/
}
```

`rgba()` controla apenas a transparência da **cor de fundo**.  
`opacity` controla a transparência **de todo o elemento**, incluindo texto, bordas e o fundo.
#### Background Image

Com o CSS nós podemos definir uma imagem de fundo para qualquer elemento HTML. Para isso basta usar a propriedade `background-image`.

```css
/*Aqui estamos definindo uma imagem de fundo para o body*/
body {
	background-image: url("link-da-imagem.png");
}
```

#### Propriedade background-repeat

Quando adicionamos uma imagem de fundo no CSS, por padrão, a imagem vai repetir diversas vezes verticalmente e horizontalmente. Algumas imagens podem repetir apenas horizontalmente ou apenas verticalmente, deixando o site visualmente estranho. 

Se o objetivo for repetir a imagem apenas horizontalmente podemos usar o seguinte comando:

```css
body {
  background-image: url("gradient_bg.png");  
  background-repeat: repeat-x; /*Aqui definimos que a imagem de fundo repita apenas horizontalmente, repeat-y para repetir na vertical*/
}
```

Se decidirmos em não permitir que a imagem seja repetida, usaremos `no-repeat` como valor da propriedade.

```css
body {
  background-image: url("gradient_bg.png");  
  background-repeat: no-repeat;
}
```

#### Propriedade background-position

Nós podemos definir a posição da imagem de fundo utilizando a propriedade `background-position`.

```css
body {
  background-image: url("gradient_bg.png");  
  background-repeat: no-repeat;
  background-position: center;
}
```

Essa propriedade pode aceitar até 2 valores, sendo o primeiro responsável pelo eixo X e o segundo pelo eixo Y. Temos alguns valores para essa propriedade: 
- left top  
- left center
- left bottom 
- right top  
- right center  
- right bottom  
- center top  
- center center  
- center bottom
- center
- usar % para definir o eixo horizontal e vertical (ex: 10% (horizontal) 30% (vertical))
- inherit (herdado do elemento pai)

#### Propriedade background-attachment

A propriedade `background-attachment` define se a imagem vai ficar fixa na tela ou vai seguir com o scroll.

```css
body {
  background-image: url("gradient_bg.png");  
  background-repeat: no-repeat;
  background-position: center;
  background-attachment: fixed; /*Ou scroll*/
}
```


#### Propriedade background-size

Essa propriedade nos permite especificar o tamanho da imagem do plano de fundo. O valor padrão dessa propriedade é `auto`. Outros valores para essa propriedade é: `cover`, `contain`, `100%`

```css
body {
  background-image: url("gradient_bg.png");  
  background-repeat: no-repeat;
  background-position: center;
  background-attachment: fixed;
  background-size: cover;
}
```
#### Modo abreviado

Para facilitar o trabalho para tirar a necessidade de escrever 4 propriedades, o CSS nos permite escrever de forma abreviada essas propriedades.

```css
/* Cor | Imagem | Posição / Tamanho | Repetição */
body {
	background: #333 url('bg.png') center / cover no-repeat;
}
```

A ordem dos valores no shorthand `background` é flexível, mas manter um padrão melhora a legibilidade.

## Tipografia

Agora vamos aprender algumas propriedades CSS para estilizar textos e fontes.
No CSS, as propriedades de fonte definem a aparência das fontes (tamanho, estilo, tipo, peso), enquanto as propriedades de texto cuidam do alinhamento,  espaçamento e decoração.

### Propriedades de fonte

#### font-family

A propriedade font-family é usada para especificar a fonte que o elemento irá usar. 

```css
p {
  font-family: "Times New Roman", sans-serif;
}
```

Nesse exemplo estou definindo que todos os elementos `p` do arquivo HTML usarão a fonte *Times New Roman*.

>[!Warning] Atenção
>Nota-se que passamos mais de uma fonte na propriedade font-family, isso serve como um *fallback*, ou seja, se a primeira fonte  não estiver disponível, ele vai tentar usar a segunda e assim por diante

#### font-style

A propriedade font-style vai definir um estilo para o texto. 
Essa propriedade pode ter um desses valores a seguir:

- *normal* - O texto vai ser exibido na sua forma normal
- *italic* - O texto vai ser exibido em itálico
- *oblique* - O texto vai ser exibido de uma forma inclinada (bem similar ao itálico)

```css
p {
  font-style: italic;
}
```

#### font-weight

A propriedade font-weight vai definir a finura ou espessura do texto.
A propriedade pode ter um desses valores:

- *normal* - Este é o valor padrão
- *bold* - Deixa o texto mais grosso
- *bolder* - Deixa o texto mais grosso ainda
- *lighter* - Deixa o texto mais fino
- *100-900* - Define a espessura do texto, indo do mais fino para o mais grosso. 400 é o mesmo que o valor *normal*, *700* é o mesmo que o bold.

```css
p {
  font-weight: bolder;
}
```

#### font-size

A propriedade font-size vai especificar o tamanho do texto.
Podemos utilizar valores relativos e absolutos para definir o font-size.

*Valores absolutos*: `px`
*Valores relativos*: `em`, `rem`, `%` , `smaller` e `larger`

Usando `px`.

O pixel é a unidade mais fácil de entender. Se você dizer que o elemento terá 24px, ele terá exatamente esse tamanho. 


```css
p {
  font-size: 24px; /*Tamanho fixo*/
}
```

Usando o `rem`

O `rem` é uma unidade relativa. Ele vai levar em consideração o tamanho da fonte do elemento root, ou seja, o tamanho da fonte do elemento HTML.

Por padrão, o `font-size` do elemento HTML é `16px`

Logo:

- 1 rem = 16px
- 2 rem = 32px

```css
html {
	font-size: 16px; /*Define a base*/
}

p {
	font-size: 1rem; /*1x o valor da base = 16px*/
}
```


#### Usando fontes externas

Além de poder selecionar as fontes disponíveis por padrão, podemos também usar fontes externas.
Geralmente usamos o **Google Fonts** para essa finalidade

Para isso:

1. Devemos acessar a plataforma do Google Fonts https://fonts.google.com/
2. Escolher uma fonte
3. Clicar em `Get font` ou `Obter Fonte`
4. Clicar no botão `<> Get Embed code`
5. E copiar a forma que desejar.

O Google Fonts disponibiliza o código da fonte para ser usado de duas maneiras:
1. Por meio da tag LINK
2. Por meio do comando @Import

Para usar a fonte pela primeira opção iremos colocar o código fornecido dentro da tag HEAD, no HTML.

```html
<head>
	<link rel="preconnect" href="https://fonts.googleapis.com">
	<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
	<link href="https://fonts.googleapis.com/css2?family=Roboto:ital,wght@0,100..900;1,100..900&display=swap" rel="stylesheet">
</head>
```

Para usar a segunda opção, basta copiar o código fornecido e colar no topo do documento CSS

```css
@import url('https://fonts.googleapis.com/css2?family=Roboto:ital,wght@0,100..900;1,100..900&display=swap');
```

Aplicando a fonte que acabamos de importar.

```css
/* Aplicando a fonte Roboto em todo o corpo do site */
body {
  font-family: "Roboto", sans-serif;
}
```

### Propriedade de Texto

#### text-align

A propriedade `text-align` é utilizada para definir o alinhamento horizontal do texto.
Essa propriedade pode usar qualquer um desses valores:

- `left`: alinha o texto a esquerda
- `right`: alinha o texto a direita
- `center`: alinha o texto ao centro
- `justify`:  estica as linhas para que cada uma tenha um width igual

```css
p {
  text-align: center; /*Todos os parágrafos centralizados*/
}
```


#### text-decoration

A propriedade `text-decoration` é usada para adicionar linhas decorativas no texto, como por exemplo, a linha do elemento `<a>`. Seu uso mais comum é remover o sublinhado desse elemento.

Valores aceitos por essa propriedade:

- `none`: Remove qualquer decoração.
- `underline`: Adiciona uma linha abaixo do texto
- `line-through`: Adiciona uma linha no meio do texto, riscado.

```css
a {
  text-decoration: none; /* Remove o sublinhado de todos os links */
}
```

#### text-transform

A propriedade `text-transform` é utilizada para controlar a capitalização do texto via CSS, independente de como o texto foi escrito

Valores aceitos:

- `none`: Sem transformação, do jeito que o texto está.
- `capitalize`: Transforma a primeira letra de cada letra em maiúscula
- `uppercase`: Transforma todos os caracteres em maiúsculo
- `lowercase`: Transforma todos os caracteres em minúsculo

```css
p{
	text-transform: capitalize; /*Todas os textos com a primeira letra em maiúsculo*/ 
}
```

#### line-height

A propriedade `line-height` define a altura da linha. Serve para definir um "respiro" entre uma linha e outra.

```css
p {
  font-size: 16px;
  line-height: 1.5; /*Espaçamento confortável (1.5x o tamanho da fonte)*/
}
```


## Desafio 

**Objetivo:** Utilizar conhecimentos de cores, background, tipografia e formatação de texto para estilizar uma "Capa de Artigo" simples.

### 1. Copie o código HTML abaixo e tente atingir os objetivos usando apenas CSS.

```html
<!DOCTYPE html>
<html lang="pt-br">
	<head>
	    <meta charset="UTF-8">
	    <title>Desafio CSS</title>
	    <link rel="stylesheet" href="style.css">
	</head>
	<body>
	
	    <h1>O Futuro da Web</h1>
	    <h2>como a tecnologia muda o mundo</h2>
	    
	    <p>
	        A tecnologia avança <span class="destaque">rapidamente</span>. Novas ferramentas surgem todos os dias para facilitar a vida dos desenvolvedores e criar experiências incríveis para os usuários.
	    </p>
	
	    <a href="#">Ler artigo completo</a>
	
	</body>
</html>
```

### 2. As Tarefas (CSS)

Siga os passos abaixo para estilizar a página:

**1. Configuração do Fundo (Background)**

- Defina uma **imagem de fundo** para o `body` (pegue qualquer imagem da internet).    
- A imagem deve cobrir toda a tela (`cover`).
- A imagem deve ficar fixa quando rolar a página (`fixed`).
- Garanta que a imagem não se repita (`no-repeat`).

**2. Tipografia Global (Google Fonts)**

- Vá ao Google Fonts e importe a fonte **"Poppins"** ou **"Roboto"**.
- Defina que o `html` terá um tamanho de fonte base de `16px`.
- Aplique a fonte importada em todo o `body`.
- Mude a cor de todo o texto do `body` para branco (ou uma cor que contraste com sua imagem).

**3. Títulos (H1 e H2)**

- **H1:**
    - O texto deve ficar totalmente em maiúsculo (`uppercase`).
    - O alinhamento deve ser centralizado.
    - O tamanho da fonte deve ser `3rem`.
- **H2:**
    - Deve ser itálico.
    - O peso da fonte deve ser mais leve (`lighter` ou `300`).
    - Alinhamento centralizado.

**4. O Parágrafo**
- Defina uma altura de linha (`line-height`) de `1.6` para facilitar a leitura.
- O tamanho da fonte deve ser `1.2rem`.
- O alinhamento deve ser centralizado ou justificado.

**5. O Link e Destaque**
- **Link (`a`):** Remova o sublinhado padrão (`none`).
- **Span (`.destaque`):** Mude a cor dessa palavra para uma cor chamativa (ex: amarelo ou ciano) e deixe o peso da fonte em negrito (`bold`).
