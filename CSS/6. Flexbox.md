Agora vamos partir para o conceito de alinhamento de itens. O flexbox nos permite alinhar, de forma unidirecional, nossos elementos no nosso site, de forma que fiquem de acordo com o projeto solicitado.

O valor `flex` pertence a propriedade `display` e é utilizada por elementos pai que querem alinhar seus filhos, horizontalmente ou verticalmente.

Anteriormente vimos que para deixar um elemento com escopo de bloco teríamos que alterar o `display` do elemento para `inline-block`, mas ao utilizar esse valor consequentemente aparecia uma margin fantasma. Usar `display: flex` facilita o alinhamento desses itens no mesmo eixo, sem gerar bugs visuais como o `inline-block`

<div style="display: flex;border: 3px solid black">
	<div style="width: 100px;height:100px; background-color: purple;color:white;font-size:24px;font-weight:bolder;">
	1
	</div>
	<div  style="width:100px;height:100px; background-color: orange;color:white;font-size:24px;font-weight:bolder;">
	2
	</div>
</div>


> O elemento que deve receber a propriedade `display:flex` sempre é o pai dos elementos que se quer organizar.


### flex-direction

Por padrão, quando definimos que um elemento vai ter o `display: flex`, os elementos são alinhados no eixo horizontal, como vocês podem perceber no exemplo anterior. Esse comportamento pode ser alterado utilizando a propriedade `flex-direction` e essa propriedade aceita alguns valores, como:

- `row`: Valor padrão
- `column`: Organiza o conteúdo em colunas
- `row-reverse`: Organiza o conteúdo em linhas, mas da direita para esquerda
- `column-reverse`: Organiza o conteúdo em colunas, mas de baixo para cima
- `initial`: Define a propriedade para seu valor inicial (`row`)
- `inherit`: Herda o valor do elemento pai

### justify-content

A propriedade `justify-content` serve para alinhar o conteúdo da melhor forma. Ele vai alinhar o conteúdo de acordo com o eixo atual, horizontal ou vertical. 

> [!TIPS] Dica
> Se o `flex-direction` for `row`, o `justify-content` mexe na horizontal. Se `flex-direction` for `column`, mexe na vertical



Essa propriedade pode receber os seguintes valores:

- `flex-start`: Valor padrão, alinha tudo no início
- `flex-end`: Alinha tudo ao final
- `center`: Centraliza os elementos no meio do container
- `space-between`: Cola o primeiro item no inicio, o último elemento no fim e distribui igualmente os outros elementos.
- `space-around`: Cria um espaçamento igual ao redor de cada item.
- `space-evenly`: Cria um espaçamento visualmente igual entre todos os itens e as bordas.

### align-items

A propriedade `align-items` é utilizada para alinhar os elementos quando eles não usam todo o espaço disponível, de acordo com o `cross axis`, eixo transversal. Ela controla como os itens se comportam na direção contrária ao fluxo principal.

> [!TIPS] Dica
> Se o `flex-direction` for `row`, o `align-items` mexe na Vertical. Se `flex-direction` for `column`, mexe na horizontal.

Assim como o `justify-content`, o `align-items` pode receber alguns valores:

- `stretch (ou normal)`: Estica os items para caber no espaço 
- `center`: Centraliza os elementos no eixo transversal.
- `flex-start`: Alinha os elementos no inicio do eixo transversal
- `flex-end`: Alinha os elementos no final do eixo transversal
- `baseline`: Alinha os itens de acordo com a linha base do texto (útil para fontes de tamanhos diferentes).

> [!NOTE] Nota
> Para ver o alinhamento na vertical, é necessário que o container pai tenha um `height` definido que seja maior que o de seus filhos


<section style="display: flex; align-items: stretch; height: 150px; border: 3px solid black;">

    <div style="width: 50px; background-color: orange;color:white;font-size:24px;font-weight:bolder;">2</div>

### flex-wrap

Nós já aprendemos como alinhar e organizar os filhos de um elemento, mas o que acontece se colocar muitos elementos filhos dentro de um elemento pai ? Eles vão ficar espremidos. 
Para isso usamos a propriedade `flex-wrap`, com ela os elementos vão automaticamente fazer a quebra de linha.

Essa propriedade recebe 3 tipos de valores:

- `nowrap`: Padrão, indica que os elementos não quebrem de linha automaticamente. Os elementos serão espremidos no container
- `wrap`: Permite que os elementos quebrem de linha automaticamente
- `wrap-reverse`: Quebra a linha, mas joga os elementos para a linha de cima.

### align-content

Você deve ter notado que ao usar o `flex-wrap` e o conteúdo se ajustar nas suas devidas posições, acabou por criar um espaço em branco entre eles. Para resolver isso vamos usar o `align-content`. Essa propriedade pode receber esses valores:

- `center`: Joga todas as linhas para o centro.
- `stretch (default)`: As linhas esticam para ocupar todo o espaço vertical.
- `flex-start`: Joga todas as linhas para o topo.
- `flex-end`: Joga todas as linhas para o final.
- `space-around`: Espaçamento ao redor das linhas.
- `space-between`: A primeira linha cola no topo, a última no fundo, e o espaço sobra no meio.

> [!WARNING] **Atenção:** 
> Essa propriedade só funciona se houver quebra de linha (`wrap`) e altura sobrando no container.

### GAP

Quando estamos desenvolvendo nossas aplicações web, normalmente colocamos um espaço entre os elementos com `margin` para dar um "respiro" entre eles. Mas quando estamos usando o `display:flex` isso fica mais facilitado com o uso da propriedade `gap`. 

Ao utilizar essa propriedade, nos podemos definir o espaçamento entre todos os itens, sem precisar usar o margin em cada elemento.


<section style="display: flex;flex-wrap: wrap; align-items: center; height: 200px; border: 3px solid black;align-content:flex-start;gap: 10px">
    <div style="width: 300px; height: 50px; background-color: purple;color:white;font-size:24px;font-weight:bolder;">1</div>
    <div style="width: 300px; height: 50px; background-color: orange;color:white;font-size:24px;font-weight:bolder;">2</div>
    <div style="width: 300px; height: 50px; background-color: blue;color:white;font-size:24px;font-weight:bolder;">3</div>
    <div style="width: 300px; height: 50px; background-color: cyan;color:white;font-size:24px;font-weight:bolder;">4</div>
    <div style="width: 300px; height: 50px; background-color: red;color:white;font-size:24px;font-weight:bolder;">5</div>
    <div style="width: 300px; height: 50px; background-color: black;color:white;font-size:24px;font-weight:bolder;">6</div>
</section>

```html
<!--gap: 10px-->
<section style="display: flex; flex-wrap: wrap; align-items: center; height: 200px; border: 3px solid black;align-content:flex-start;gap:10px">
    <div style="width: 300px; height: 50px; background-color: purple;color:white;font-size:24px;font-weight:bolder;">1</div>
    <div style="width: 300px; height: 50px; background-color: orange;color:white;font-size:24px;font-weight:bolder;">2</div>
    <div style="width: 300px; height: 50px; background-color: blue;color:white;font-size:24px;font-weight:bolder;">3</div>
    <div style="width: 300px; height: 50px; background-color: cyan;color:white;font-size:24px;font-weight:bolder;">4</div>
    <div style="width: 300px; height: 50px; background-color: red;color:white;font-size:24px;font-weight:bolder;">5</div>
     <div style="width: 300px; height: 50px; background-color: black;color:white;font-size:24px;font-weight:bolder;">6</div>
</section>
```

Nesse exemplo eu coloquei `gap: 10px` e foi criado um espaçamento entre os itens, criando um "respiro" entre eles.
