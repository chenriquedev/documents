Como vimos no módulo de HTML, os elementos possuem, por padrão, certos comportamentos. 

Um exemplo rápido disso é o comportamento que uma `div` tem em ocupar 100% da largura da tela independente do conteúdo que ela contenha.

<div style="height:100px;border:3px solid black">
</div>

Outro exemplo é uma tag `<a>`, hyperlink, que ficam lado a lado, e sua largura depende do conteúdo mostrado

<a href="#">Este é um link</a> <a href="#">Este é outro link</a>

Esse comportamento se dá por conta da propriedade `display`. 

Os elementos de bloco ocupam 100% da largura da tela, enquanto elementos de linha ocupam apenas o espaço necessário para mostrar a informação.

Alguns elementos de bloco são:
- `div`
- `p`
- `section`
- `article`
- `h1,h2,h3...`

e alguns elementos de linha:
- `a`
- `img`
- `strong`
- `br`

Com o CSS conseguimos manipular esse valor por meio da propriedade `display` e essa propriedade vai aceitar esses valores:

- `block`: Elementos ficam com comportamento de tag de bloco. Esses elementos aceitam receber propriedades como `width` e `height`
- `inline`: Elementos ficam com comportamento de tag de linha. Esses elementos não são afetados pelas propriedades `width`,`height`, `margin-top` e `margin-bottom`.
- `inline-block`: O elemento vai ter o comportamento de ambos. Vai ocupar apenas o espaço necessário para mostrar o conteúdo e vão ser afetados por propriedades `width` e `height`.
- `flex`: Cria um container Flex
- `grid`: Cria um container Grid
- `none`: Simplesmente some com o elemento e o espaço que antes era reservado para ele
### Exemplos: 

<div style="width:100%;height:250px;border:3px solid black">
	<div style="height:100px;border:3px solid black;background-color: #A9CDDD">
	</div>
	<div style="height:100px;border:3px solid black;background-color:#FFA500">
	</div>
</div>

Nesse exemplo, temos duas div's, sem width definidos ocupando 100% da largura. O comportamento padrão é que elementos do tipo `block` comecem em uma nova linha e ocupem 100% da largura da tela

```html
<div style="width:100%;height:250px;border:3px solid black">
	<div style="height:100px;border:3px solid black;background-color: #A9CDDD">
	</div>
	<div style="height:100px;border:3px solid black;background-color:#FFA500">
	</div>
</div>
```


<div style="width:100%;height:250px;border:3px solid black">
	<a href="#" style="width:100px">
	link 1
	</a>
	<a href="#" style="width:100px">
	link 2
	</a>
</div>

Nesse exemplo temos 2 links. Link por padrão tem o escopo `inline` (linha) e para cada novo elemento de linha criado eles ficam lado-a-lado. 

```html
<div style="width:100%;height:250px;border:3px solid black">
	<!--Mesmo com width definido, o elemento não é afetado-->
	<a href="#" style="width:100px">
	link 1
	</a>
	<a href="#" style="width:100px">
	link 2
	</a>
</div>
```

<div style="width:100%;height:250px;border:3px solid black">
	<div style="display:inline;height:100px;border:3px solid black;background-color: #A9CDDD">
		div 1
	</div>
	<div style="display:inline;height:100px;border:3px solid black;background-color:#FFA500">
		div 2
	</div>
</div>

Agora eu peguei o primeiro exemplo das div's e transformei elas, por meio da propriedade `display` em elementos de linha. Veja como o comportamento mudou.

```html
<div style="width:100%;height:250px;border:3px solid black">
	<div style="display:inline;height:100px;border:3px solid black;background-color: #A9CDDD">
		div 1
	</div>
	<div style="display:inline;height:100px;border:3px solid black;background-color:#FFA500">
		div 2
	</div>
</div>
```


<div style="width:100%;height:250px;border:3px solid black">
	<a href="#" style="display:block"> 
	link 1
	</a>
	<a href="#" style="display:block">
	link 2
	</a>
</div>

Ao mudar os links para o `display:block` esse é o resultado obtido.

```html
<div style="width:100%;height:250px;border:3px solid black">
	<a href="#" style="display:block">
	link 1
	</a>
	<a href="#" style="display:block">
	link 2
	</a>
</div>
```

<div style="width:100%;height:250px;border:3px solid black">
	<div style="display:inline-block;width:100px;height:100px;border:3px solid black;background-color: #A9CDDD">
	</div>
	<div style="display:inline-block;width:100px;height:100px;border:3px solid black;background-color:#FFA500">
	</div>
</div>

Agora veja esse comportamento, dessa vez eu peguei as div's e coloquei o `display:inline-block`. Veja que as caixas ficaram uma ao lado da outra, usando o comportamento dos elementos `inline` e recebendo propriedades como `width` que só é aceita por elemento `block`. 

```html
<div style="width:100%;height:250px;border:3px solid black">
	<div style="display:inline-block;width:100px;height:100px;border:3px solid black;background-color: #A9CDDD">
	div 1
	</div>
	<div style="display:inline-block;width:100px;height:100px;border:3px solid black;background-color:#FFA500">
	div 2
	</div>
</div>
```

> [!WARNING] Atenção
> Esse espaçamento entre as caixas com `display:inline-block` trata-se de um erro crônico. Basicamente é uma margin fantasma, não existe, mas ta ali

### Propriedades width e height

As propriedades `width` e `height` são usadas para definir a largura e a altura do elemento, respectivamente.

Podemos utilizar as seguintes unidades de medidas para ambos:
- `px`
- `rem`
- `em`
- `%`

E cada um tem valor individual, como `vw` para width e `vh` para height.

<div style="width:200px;height:200px;border:1px solid black;">
</div>

Nesse caso eu defini que essa div, que tem escopo de bloco, vai ter 200px de largura e 200px de altura fixa.

```html
<div style="width:200px;height:200px;border:1px solid black;">
</div>
```

Em alguns casos precisamos definir a largura de acordo com o percentual da tela, utilizando o `%` ou `vw`, e com isso o elemento pode crescer muito mais que o esperado, pois no mercado atualmente possuímos telas enormes. Para resolver esse problema, temos a propriedade `max-width`, que define um tamanho máximo de largura e que o container não ultrapasse o tamanho definido. A mesma coisa vale para a propriedade `min-width` que não deixa o container ou elemento encolher muito.

> [!TIPS] Dica
> Quando estamos trabalhando com imagens, geralmente usamos `max-width: 100%` para que a imagem nunca fique maior do que o elemento pai.

### Overflow

No exemplo anterior nós definimos que o meu container terá um `min-height: 200px` mas e se eu quisesse deixar ele pequeno e mesmo assim eu conseguir ver o conteúdo?

No CSS temos a propriedade `overflow` que nos ajuda nesse quesito.

para essa propriedade, temos os seguintes valores:

- `visible`: O padrão. O conteúdo vaza e fica por cima de tudo.
- `hidden`: O que não couber será cortado (escondido) e o resto do conteúdo fica inacessível.
- `scroll`: Adiciona barras de rolagem (horizontal e vertical) para ver o conteúdo escondido.
- `auto`: O navegador decide. Se precisar de scroll, ele coloca. Se não precisar, ele não coloca. (É a melhor opção na maioria das vezes).

```css
.caixa-com-scroll {
    width: 300px;
    height: 150px;
    border: 1px solid black;
    /* Adiciona scroll apenas se necessário */
    overflow: auto; 
}
```

> [!TIPS] Dica Avançada 
> Você também pode controlar a rolagem apenas na horizontal ou vertical usando `overflow-x` ou `overflow-y`.
